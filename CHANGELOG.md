# Wi-Fi Commander version notes

## 2.1.1

- Restores the original main and diagnostic screen layouts from version 2.0.0 HF1, including their information density, font sizes, and formatting.
- Removes the 2.1 larger-font, expanded row/column, additional scrolling-panel, and window-sizing changes.
- Retains the compact first-launch and expired-trial activation dialogs.
- Keeps the diagnostic engines, artwork, RDP cleanup behavior, worker shutdown, and licensing storage unchanged from that package.

This release does not claim an ultra-wide display compatibility fix. See the [official product page](https://aicreatenow.com/WiFiCommander.html) for the current release and compatibility notices.

These notes summarize the publisher's supplied version 2.1.1 change record.
