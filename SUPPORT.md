[Official product page and download](https://aicreatenow.com/WiFiCommander.html) · [Privacy policy](https://aicreatenow.com/WiFiCOMPrivacy.html)

## What to include

- Wi-Fi Commander version and Windows version.
- The tool or screen affected and the steps to reproduce the issue.
- Expected behavior and what actually happened, including the exact error text.
- Whether you use Wi-Fi or Ethernet; include the adapter model and driver version when relevant.
- For layout problems, include screen resolution, Windows display scaling, and whether the display is ultra-wide or curved.
- A screenshot with private details removed, if it helps explain the problem.

## Before sharing

Public GitHub issues and screenshots can be seen by anyone. Remove license keys, computer names, public IP addresses, Wi-Fi network names, BSSIDs/MAC addresses, internal hostnames, and other sensitive information you do not intend to publish. Never post passwords or payment details.

Send activation and purchase questions through private support. Do not publish your license key in an issue.

## Useful checks

- Wi-Fi scans require an enabled, compatible Wi-Fi adapter. Check the Windows Location / nearby-network permission requested by Windows.
- Internet diagnostics require Internet access and can use data, especially download benchmarks.
- A mesh session stops when the connection or access point changes. Restart the session to continue from the new connection.
- Public TCP reachability results apply to the public IPv4 address. They do not identify which device behind a router answered.
- The current product page reports layout issues on ultra-wide and curved-monitor configurations. Check it for hotfix availability.

Network diagnostic tools and remote services can return incomplete results when a device, network, firewall, or service does not respond. Include the displayed error or result when contacting support.
